## 1. 文档概述

### 1.1 文档目的
本文档旨在定义叙事引擎编辑页的产品需求，明确功能范围、用户交互流程及验收标准，为开发团队提供清晰的产品实现指导。

### 1.2 产品背景
叙事引擎编辑页是场景演示大师产品的核心功能模块，用于帮助内容创作者通过可视化方式配置交互演示流程。用户无需编程知识，通过双击场景中的控点即可自动录制交互节点，大幅降低交互内容创作门槛。

### 1.3 目标用户
- **主要用户**：场景演示内容创作者、产品演示策划人员
- **次要用户**：交互设计师、产品经理
- **用户特征**：具备基本计算机操作能力，无需编程背景

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| **叙事线** | 一条完整的交互演示流程，由多个交互节点按顺序组成 |
| **交互节点** | 用户在场景中双击控点后创建的操作单元，包含操作类型、操作对象和事件序列 |
| **交互事件序列** | 预设的事件执行顺序，用户不可编辑 |
| **起始节点** | 每条叙事线有且仅有一个Root节点，定义叙事流的初始环境 |
| **静默跳转** | 播放预览时，在进入节点前瞬间强制切换场景，用户无感知 |

### 3.2 核心功能模块

#### 3.2.1 起始节点 

**功能描述：**
- 每条叙事线有且仅有一个起始节点，不可删除
- 初始默认为项目首页
- 支持编辑，可选项为当前项目所有场景页，用户可根据需要切换起始节点
- [ ] 起始节点固定为0号节点，有专门标识，不占用叙事线节点序号，不可删除、不可排序

#### 3.2.2 节点自动捕获机制

**功能描述：**
用户在预览区双击任意交互控点，系统自动创建新节点并回填相关参数。

**触发条件：**
- 在预览区双击控点
- 控点必须具有有效的交互事件

**自动回填逻辑：**

| 参数项 | 回填规则 | 示例 |
|--------|----------|------|
| 节点名称 | 默认回填[控点名称] | "功能入口按钮" |
| 操作类型 | 默认回填该控点预设的交互类型 | "点击弹出" |
| 操作页面 | 自动记录当前控点所属的场景ID | "Index_Home" |
| 操作控点 | 记录该控点的唯一ID | "btn_001_feature" |
| 快照 | 捕获触发瞬间的Canvas画面 | 卡片缩略图 |


#### 3.2.3 逻辑连贯性与异常校验

**功能描述：**
系统根据捕获的参数，自动判定节点间的流转关系并给出视觉反馈。

**校验规则：**

| 判定项 | 判定条件 | 系统处理策略 | UI表现 |
|--------|----------|--------------|--------|
| **场景衔接** | 当前节点与上一节点的"页面ID"不一致 | **静默跳转**：播放预览时，在进入当前节点前瞬间强制切场 | 节点间连线显示为**红色虚线**，标注"静默跳转" |
| **数据异常** | 自动回填失败导致必填项（如控点ID）缺失 | **异常高亮**：提醒用户：该节点无效，建议删除重录 | 节点卡片显示**红色感叹号**，悬停显示异常原因 |



#### 3.2.4 节点编辑与配置

**功能描述：**
用户可对已创建的节点进行编辑和参数调整。

**可编辑项：**
- 节点名称（自定义）
- 节点描述（自定义）
- 操作类型（修改后自动更新事件序列）及对应的联动字段


#### 3.2.5 播放预览功能

**功能描述：**
支持对单个节点或整条叙事线进行播放预览。

##### 3.2.5.1 单节点播放预览

**功能描述：**
对当前选中的单个节点进行交互事件序列的播放预览。

**播放控制：**
- **播放按钮**：执行当前选中节点的交互事件序列
- **停止按钮**：重置节点到初始状态

**交互逻辑：**
- 点击播放按钮后，按顺序执行该节点的所有交互事件
- 点击停止按钮，立即停止播放并重置到节点初始状态


##### 3.2.5.2 整条叙事线预览

**功能描述：**
按顺序逐个节点执行，模拟完整的叙事流程。

**播放控制：**
- **上一步按钮**：回退到上一个节点，重置到该节点的初始状态
- **下一步按钮**：执行当前节点的交互事件序列，完成后前进到下一个节点

**交互逻辑：**
- 初始状态：选中起始节点，等待用户操作
- 点击"下一步"：执行**下一个节点**的所有交互事件序列，执行完成后选中该节点
- 点击"上一步"：回退到**上一个节点**并执行其所有交互事件序列，执行完成后选中该节点
- 支持连续点击"下一步"、"上一步"按钮，按顺序遍历所有节点
- 处于起始节点时，"上一步"按钮禁用
- 处于最后一个节点且播放完成时，"下一步"按钮禁用
- 当存在"静默跳转"（场景衔接不一致）时，在节点切换前自动完成场景切换
- 回退时同样触发"静默跳转"切换到对应场景

**连续操作打断机制：**
- 当节点正在播放时，点击"下一步"/"上一步"按钮，立即打断当前播放
- 打断后根据点击的按钮执行对应操作

*节点进度状态显示：**
- 已执行节点数/总节点数


#### 3.2.6 叙事线设置

**功能描述：**
支持对叙事线全局参数进行配置。

**设置项：**

| 设置项 | 类型 | 说明 |
|--------|------|------|
| **点击动效** | 下拉选择 | 设置节点点击时的动效，默认"无"，可选其他动效类型 |
| **远程控制** | 开关 | 开启/关闭远程控制功能，开启后支持远程操控叙事线播放 |

**触发方式：**
- 点击顶部工具栏设置按钮打开叙事线设置弹窗

**操作按钮：**
- **取消**：关闭弹窗，不保存修改
- **保存**：保存设置并关闭弹窗

#### 3.2.7 节点管理操作

**功能描述：**
支持对节点进行增删改查和排序操作。

**操作列表：**

| 操作 | 触发方式 | 说明 |
|------|----------|------|
| 添加节点 | 双击预览区控点 | 自动创建并回填参数 |
| 编辑节点 | 点击节点卡片右上角编辑按钮 | 打开节点配置弹窗，可修改节点名称和描述 |
| 删除节点 | 点击更多按钮 → 选择删除 | 起始节点不可删除，需二次确认 |
| 上移节点 | 点击更多按钮 → 选择上移 | 与上一个节点交换位置，起始节点不可上移 |
| 下移节点 | 点击更多按钮 → 选择下移 | 与下一个节点交换位置 |
| 选择节点 | 点击节点卡片主体区域 | 选中节点，更新左侧预览区展示内容，自动执行一次节点预览 |

**更多菜单说明：**
- 触发方式：点击节点卡片右上角的更多按钮（三个点图标）
- 菜单内容：
  - 删除
  - 上移
  - 下移
- 菜单项状态：
   0- 起始节点无更多按钮
  - 第一个节点的"上移"选项禁用
  - 最后一个节点的"下移"选项禁用

## 7. 附录

### 7.1 操作类型定义

系统支持的操作类型及对应属性：

| 操作类型 | 自动生成操作描述 | 是否有事件序列 | 说明 |
|----------|------------------|----------------|------|
| 点击控点 | "点击控点[控点名称]" | 是 | 双击场景中的交互控点创建节点，记录点击操作及后续交互事件序列 |
| 通过导航切换页面 | "切换至[目标页面名称]" | 否 | 通过导航栏切换页面，仅记录页面切换结果，无交互事件序列 |
| 点击关闭窗口按钮 | "点击关闭窗口按钮" | 否 | 点击弹窗或窗口的关闭按钮 |
| 还原为全景视图 | "还原为全景视图" | 否 | 从聚焦/放大状态还原到全景视图 |
| 取消区域聚焦 | "取消区域聚焦" | 否 | 取消当前的区域聚焦效果 |

#### 7.1.1 有事件序列的操作类型

**点击控点**类型包含交互事件序列，系统根据控点预设的交互事件自动生成对应的事件序列。每个事件是序列中的一条数据：

| 交互事件 | 交互事件描述 | 说明 |
|----------|--------------|------|
| 弹出内容 | 弹出内容[内容文件名称] | 弹出视频、图片等内容文件 |

#### 7.1.2 无事件序列的操作类型

以下操作类型**无交互事件序列**，节点卡片中不显示交互事件列表：

- 通过导航切换页面
- 点击关闭窗口按钮

- 取消区域聚焦

这些操作执行后立即完成，无需事件序列展示。
