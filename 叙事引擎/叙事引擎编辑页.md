# 叙事引擎编辑页功能需求文档

## 一、产品定位与目标用户

### 1.1 产品定位
叙事引擎编辑页是一个可视化交互配置工具，用于记录和配置用户双击场景中的控件（控点）后触发的多个交互事件序列。

### 1.2 目标用户
- 场景演示内容创作者
- 产品演示策划人员
- 交互设计师

### 1.3 核心价值
- **低门槛**：无需编程知识，通过可视化操作完成配置
- **高效率**：双击即可添加交互节点，自动生成事件序列
- **可视化**：所见即所得，实时预览交互效果
- **简洁专注**：主界面聚焦核心功能，高级配置按需展开

## 二、核心概念说明

### 2.1 叙事线
一条完整的交互演示流程，由多个交互节点按顺序组成。

### 2.2 交互节点
用户在场景中双击控点后创建的操作单元，包含：
- 操作类型（如跳转场景、显示弹窗等）
- 操作对象（控点）
- 自动生成的交互事件序列

### 2.3 交互事件序列
系统预设的事件执行顺序，用户不可编辑。例如：点击"产品介绍"按钮 → 弹出详情窗口 → 显示高亮效果。

### 2.4 控点
场景中的可交互元素，如按钮、图片、文本等。

### 2.5 高级设置面板
包含非核心参数配置的可折叠面板，默认关闭，用户可通过明确操作打开进行修改。

## 三、典型使用场景

### 场景1：产品功能演示
用户创建一条叙事线，依次双击"功能入口"按钮、"返回"按钮，系统自动配置跳转和返回的交互事件序列。

### 场景2：操作引导流程
用户配置一条新手引导叙事线，通过双击各个引导控点，自动生成"显示提示 → 高亮区域 → 用户点击 → 关闭提示"的事件序列。

## 四、功能需求

### 4.1 叙事线管理（P0）

#### 4.1.1 叙事线创建
- 支持新建叙事线
- 叙事线名称必填，支持中文、英文、数字
- 名称长度限制：1-50字符
- 新建后自动进入编辑状态

#### 4.1.2 叙事线编辑
- 支持修改叙事线名称
- 支持删除叙事线（需二次确认）
- 支持复制叙事线（创建副本）

#### 4.1.3 叙事线保存
- 支持手动保存（保存按钮）
- 支持自动保存（每30秒或离开页面时）
- 保存成功/失败状态提示
- 保存失败时保留未保存状态

### 4.2 交互节点配置（P0）

#### 4.2.1 核心展示：交互事件序列
- **展示位置**：主界面核心区域，占据最大视觉空间
- **展示方式**：以卡片式布局展示交互事件序列
- **事件卡片设计**：
  - 每个事件独立显示为一个卡片
  - 卡片包含：事件序号、事件名称、事件描述、事件图标
  - 卡片之间用箭头连接，表示执行顺序
  - 当前执行事件高亮显示（播放时）
- **可读性优化**：
  - 事件名称使用大字体加粗显示
  - 事件描述使用较小字体，颜色稍浅
  - 事件序号使用圆形徽章，颜色区分不同阶段
  - 卡片背景使用浅色，边框清晰
- **交互功能**：
  - 悬停事件卡片时显示详细信息
  - 点击事件卡片可查看事件参数（如果有）
  - 支持事件卡片的展开/折叠

#### 4.2.2 自动描述展示
- **展示位置**：事件序列上方，醒目位置
- **展示方式**：大字体、加粗、居中显示
- **内容**：根据操作类型和参数自动生成的操作描述
- **样式**：使用强调色背景，白色文字，圆角卡片样式

#### 4.2.2.1 自动描述生成规则
系统根据操作类型和参数自动生成描述，规则如下：

**跳转场景操作**：
- 格式：`跳转至{目标场景页名称}`
- 示例：`跳转至功能详情页`

**内容弹窗操作**：
- 格式：`显示{弹窗内容名称}`
- 示例：`显示产品介绍弹窗`

**显示隐藏操作**：
- 格式：`{显示/隐藏}{目标元素名称}`
- 示例：`显示详情面板` 或 `隐藏帮助提示`

**关闭弹窗操作**：
- 格式：`关闭{弹窗名称}`
- 示例：`关闭产品介绍弹窗`

**导航栏切换操作**：
- 格式：`切换至{导航项名称}`
- 示例：`切换至设置页面`

**高亮聚焦操作**：
- 格式：`高亮{目标元素名称}`
- 示例：`高亮功能入口按钮`

**镜头移动操作**：
- 格式：`镜头移动至{目标位置}`
- 示例：`镜头移动至详情区域`

**点击弹窗关闭按钮操作**：
- 格式：`点击关闭按钮`
- 示例：`点击弹窗关闭按钮`

**默认描述生成逻辑**：
1. 优先使用用户在高级设置面板中自定义的描述
2. 如果用户未自定义，则根据操作类型和参数自动生成
3. 如果参数为空，则使用操作类型的默认描述
4. 描述长度限制：最多50个字符，超出则截断并添加"..."

#### 4.2.3 高级设置面板（默认隐藏）
- **触发方式**：点击"高级设置"按钮
- **面板形式**：弹窗式或侧边抽屉式
- **打开方式**：
  - 点击"高级设置"按钮，面板从右侧滑入
  - 面板宽度：400px，覆盖主界面右侧部分
  - 面板背景：半透明深色，带模糊效果
  - 面板顶部：关闭按钮、标题"高级设置"
- **关闭方式**：
  - 点击面板右上角关闭按钮
  - 点击面板外部区域
  - 按ESC键
- **动画效果**：
  - 打开：从右侧滑入，时长300ms，缓动函数ease-out
  - 关闭：向右滑出，时长300ms，缓动函数ease-in
  - 面板背景淡入淡出，与面板动画同步

#### 4.2.4 高级设置面板内容
- **节点名称**：
  - 输入框，默认值为"操作N"（N为节点序号）
  - 支持自定义修改
- **操作类型**：
  - 下拉选择，默认值为"点击控点-跳转场景"
  - 选项包括：
    - 点击控点-跳转场景
    - 点击控点-内容弹窗
    - 点击控点-显示隐藏
    - 点击控点-关闭弹窗
    - 导航栏切换
    - 点击弹窗关闭按钮
    - 点击控点-高亮聚焦
    - 点击控点-镜头
- **操作控点**：
  - 输入框或选择器，用于指定被操作的控件/控点
  - 默认值为双击时选中的控点
- **目标场景页**：
  - 下拉选择，仅在"跳转场景"操作类型下显示
  - 默认值为空，必填
- **智能预填充**：
  - 所有非核心参数在创建节点时自动填充默认值
  - 默认值基于操作类型和上下文智能推断
  - 用户可在高级设置面板中修改默认值

#### 4.2.5 节点预览功能
- **默认预览模式**：选中节点时，预览区直接展示该节点所有交互事件执行完成后的最终状态
- **播放预览模式**：
  - 预览区顶部显示"播放预览"按钮
  - 点击后自动播放该节点的所有交互事件序列
  - 播放速度：默认1x，支持0.5x、1x、1.5x、2x调节
  - 播放过程中显示当前执行的事件名称（如"事件1/5：显示弹窗"）
  - 支持暂停/继续播放
  - 支持单步执行（点击"下一步"按钮逐个事件执行）
- **预览状态切换**：
  - 默认显示最终状态时，按钮显示"播放预览"
  - 播放过程中，按钮显示"暂停"
  - 暂停时，按钮显示"继续"
  - 播放完成后，按钮显示"重新播放"
- **预览时长控制**：
  - 单个事件默认执行时长：500ms（可配置）
  - 整个节点预览时长 = 事件数量 × 单个事件时长
  - 最长预览时长限制：10秒（超过则提示"事件序列较长，建议分段查看"）

#### 4.2.6 预览区状态标识
- **未选中节点时**：显示"请选择一个节点查看预览"
- **选中节点但未配置时**：显示"该节点尚未配置，请先完成配置"
- **选中节点且已配置时**：
  - 默认显示最终状态，右上角显示"预览模式：最终状态"
  - 播放过程中显示"预览模式：播放中（事件N/总数）"
  - 暂停时显示"预览模式：已暂停（事件N/总数）"
- **预览加载中**：显示加载动画 + "正在加载预览..."

#### 4.2.7 主界面简洁性设计
- **核心内容优先**：交互事件序列和自动描述占据主界面80%以上空间
- **非核心内容隐藏**：所有参数设置项默认隐藏在高级设置面板中
- **视觉层次清晰**：
  - 一级：交互事件序列（最突出）
  - 二级：自动描述（次突出）
  - 三级：预览区（辅助展示）
  - 四级：高级设置按钮（入口）
- **信息密度控制**：
  - 事件卡片之间保持充足间距（至少16px）
  - 避免过多装饰元素
  - 使用留白提升可读性
- **色彩运用**：
  - 主色调：蓝色系（专业、科技感）
  - 强调色：橙色（用于高亮当前事件）
  - 成功色：绿色（用于完成状态）
  - 背景色：浅灰色（#F5F7FA）
  - 卡片背景：白色（#FFFFFF）

### 4.3 节点与事件序列管理（P0）

#### 4.3.1 节点与事件序列合并展示
- 节点时间轴和交互事件序列在左侧栏合并展示
- 上半部分显示所有节点（横向卡片式布局）
- 下半部分显示当前选中节点的事件序列（横向卡片式布局）
- 点击节点卡片切换到该节点，事件序列自动更新
- 节点卡片和事件卡片使用相同的视觉风格，保持一致性

#### 4.3.2 节点操作
- **选择节点**：点击节点卡片，事件序列区域自动更新为该节点的事件序列
- **拖拽排序**：支持拖拽节点卡片调整节点执行顺序
- **删除节点**：节点卡片悬停时显示删除按钮，点击删除需二次确认
- **复制节点**：节点卡片悬停时显示复制按钮，点击创建副本插入到当前位置
- **批量删除**：支持多选节点卡片批量删除（按住Ctrl/Cmd多选）

#### 4.3.3 节点状态管理
- 节点配置未完成时显示警告图标
- 节点配置完成显示正常状态
- 当前选中节点使用高亮边框和背景色标识
- 节点卡片之间用箭头连接，表示执行顺序

#### 4.3.4 节点预览联动
- **节点选中与预览联动**：点击节点卡片时，预览区自动更新为该节点的预览内容
- **预览模式记忆**：用户上次使用的预览模式（快速预览/播放预览）在切换节点时保持
- **预览状态保持**：切换节点后，原节点的预览状态（如暂停位置）不保存

### 4.4 叙事线预览与播放（P1）

#### 4.4.1 预览模式说明
- **节点级预览**：选中单个节点时，预览该节点的交互效果（见4.2.5）
- **叙事线级预览**：点击"播放叙事线"按钮时，按顺序播放所有节点的交互效果
- 两种预览模式独立，互不影响

#### 4.4.2 播放控制
- 播放/暂停按钮
- 停止按钮
- 进度条（可拖拽跳转）
- 播放速度调节（0.5x、1x、1.5x、2x）

#### 4.4.3 播放状态反馈
- 当前执行节点高亮显示
- 显示当前播放进度（节点N/总数）
- 播放完成提示

### 4.5 辅助功能（P1）

#### 4.5.1 操作引导
- 首次进入页面显示操作引导弹窗
- 常驻提示："双击场景中的控点添加交互节点"
- 鼠标悬停控件时显示功能提示

#### 4.5.2 快捷键支持
- Ctrl+S：保存叙事线
- Ctrl+Z：撤销（可选）
- Ctrl+Y：重做（可选）
- Delete：删除选中节点
- ESC：关闭高级设置面板

#### 4.5.3 导入导出
- 支持导出叙事线为JSON格式
- 支持导入JSON文件恢复叙事线
- 导入时验证数据格式，失败提示错误信息

## 五、交互流程设计

### 5.1 首次使用流程
1. 用户进入叙事引擎编辑页
2. 显示操作引导弹窗，介绍核心功能
3. 用户点击"开始创建"按钮
4. 输入叙事线名称，点击"创建"
5. 进入编辑界面，显示预览区和交互事件序列展示区
6. 常驻提示："双击场景中的控点添加交互节点"

### 5.2 创建交互节点流程
1. 用户在场景预览区双击某个控点
2. 系统立即创建新交互节点
3. 自动填充：操作控点、操作类型等默认值
4. 自动生成操作描述
5. 自动加载该控点对应的预设交互事件序列
6. 主界面展示交互事件序列和自动描述
7. 高级设置面板保持关闭状态
8. 用户如需修改参数，点击"高级设置"按钮打开面板
9. 用户修改参数后，描述和事件序列自动更新

### 5.3 打开高级设置流程
1. 用户点击"高级设置"按钮
2. 高级设置面板从右侧滑入，覆盖主界面右侧部分
3. 面板背景淡入，显示半透明遮罩
4. 用户可修改节点名称、操作类型、操作控点等参数
5. 修改后自动描述和事件序列实时更新
6. 用户点击关闭按钮或点击面板外部区域
7. 面板向右滑出，背景淡出
8. 主界面显示更新后的内容

### 5.4 调整节点顺序流程
1. 用户拖拽某个节点到目标位置
2. 显示拖拽预览（虚线框）
3. 释放鼠标，节点移动到新位置
4. 节点序号自动更新
5. 自动保存（如果开启自动保存）

### 5.5 删除节点流程
1. 用户点击节点删除按钮
2. 弹出确认对话框："确定要删除该节点吗？"
3. 用户点击"确定"，节点删除
4. 节点序号自动更新
5. 自动保存（如果开启自动保存）

### 5.6 保存叙事线流程
1. 用户点击"保存"按钮
2. 系统验证数据完整性：
   - 叙事线名称不能为空
   - 每个节点的必填字段必须填写
3. 验证通过，保存数据
4. 显示"保存成功"提示（3秒后自动消失）
5. 验证失败，显示错误信息，高亮错误字段

### 5.7 节点预览流程

#### 快速预览流程（默认）
1. 用户点击某个节点
2. 系统验证节点是否已配置
3. 如果未配置，显示"该节点尚未配置"提示
4. 如果已配置，直接在预览区展示最终状态
5. 右上角显示"预览模式：最终状态"
6. 用户可点击"播放预览"按钮查看完整交互过程

#### 播放预览流程
1. 用户点击"播放预览"按钮
2. 预览区重置到初始状态（事件执行前的场景）
3. 按顺序逐个执行交互事件
4. 每执行一个事件，显示当前事件名称和进度
5. 交互事件序列中当前执行的事件高亮显示
6. 所有事件执行完成后，停留在最终状态
7. 按钮变为"重新播放"

#### 暂停/继续流程
1. 用户在播放过程中点击"暂停"按钮
2. 播放立即停止，停留在当前事件执行后的状态
3. 按钮变为"继续"
4. 用户点击"继续"，从当前事件继续播放

#### 单步执行流程
1. 用户点击"单步执行"按钮
2. 执行下一个事件
3. 停留在该事件执行后的状态
4. 等待用户再次点击"单步执行"

## 六、数据模型

### 6.1 叙事线对象
```typescript
interface NarrativeLine {
  id: string;                    // 叙事线ID（UUID）
  name: string;                  // 叙事线名称（1-50字符）
  description?: string;           // 描述（可选）
  createdAt: number;              // 创建时间（时间戳）
  updatedAt: number;              // 更新时间（时间戳）
  nodes: InteractionNode[];       // 交互节点列表
  version: number;                // 版本号（用于乐观锁）
}
```

### 6.2 交互节点对象
```typescript
interface InteractionNode {
  id: string;                    // 节点ID（UUID）
  sequence: number;              // 执行顺序（从1开始）
  name: string;                  // 节点名称
  operationType: OperationType;  // 操作类型（枚举）
  sourceControlId: string;       // 操作控点ID
  targetSceneId?: string;        // 目标场景页ID（跳转场景时必填）
  autoDescription: string;       // 自动生成的描述
  eventSequence: InteractionEvent[]; // 交互事件序列
  isConfigured: boolean;         // 是否配置完成
}
```

### 6.3 操作类型枚举
```typescript
enum OperationType {
  JUMP_SCENE = 'jump_scene',              // 点击控点-跳转场景
```

## 七、界面布局设计

### 7.1 整体布局
采用两栏布局，从左到右依次为：

#### 左侧栏（预览区）- 45%宽度
- **场景预览区**（主要区域）
  - 显示场景画布
  - 展示控点位置
  - 支持双击控点创建节点
- **播放控制区**（整合在预览区底部）
  - 播放/暂停按钮
  - 停止按钮
  - 播放进度条
  - 时间显示
  - 预览模式切换按钮

#### 右侧栏（编辑区）- 55%宽度
- **自动描述展示区**（顶部，10%高度）
  - 大字体、加粗显示
  - 渐变色背景，醒目突出
  - 显示当前选中节点的自动描述

- **节点时间轴**（核心区域，70%高度）
  - 垂直列表布局
  - 每个节点显示：序号、名称、操作类型、控点
  - 当前选中节点高亮显示
  - 支持拖拽排序
  - 悬停显示操作按钮（复制、删除）
  - 点击编辑按钮打开高级设置面板

- **交互事件序列**（底部，20%高度）
  - 压缩展示
  - 横向排列的事件卡片
  - 显示事件序号和名称
  - 用箭头连接表示执行顺序

### 7.2 顶部工具栏 - 56px高度
- **左侧**：Logo + 叙事线名称输入框 + 保存状态
- **右侧**：撤销/重做按钮 + 设置按钮 + 保存按钮

### 7.3 高级设置面板
- **面板形式**：居中弹窗
- **面板尺寸**：宽度420px，自适应高度
- **面板内容**：
  - 节点名称（输入框）
  - 操作类型（下拉选择）
  - 操作控点（输入框）
  - 目标场景页（条件显示）
- **打开方式**：点击节点编辑按钮
- **关闭方式**：点击关闭按钮、点击遮罩、按ESC键

### 7.4 响应式设计
- **最小宽度**：1024px
- **屏幕宽度 < 1024px**：显示提示信息"建议使用大屏幕以获得最佳体验"
- **屏幕宽度 >= 1920px**：适当增加左侧栏宽度比例

### 7.5 色彩方案（暗黑主题）
- **主色调**：蓝紫色渐变（#6366f1 → #4f46e5）
- **辅助色**：
  - 青色（#06b6d4）- 用于进度条、高亮
  - 绿色（#10b981）- 用于成功状态
  - 红色（#ef4444）- 用于错误、删除
- **背景色**：
  - 主背景：#0f172a（深蓝黑）
  - 次级背景：rgba(30, 41, 59, 0.8)
  - 卡片背景：rgba(255, 255, 255, 0.05)
- **文字色**：
  - 主文字：#f8fafc（白色）
  - 次要文字：#94a3b8（灰色）
  - 辅助文字：#64748b（深灰）
- **边框色**：rgba(148, 163, 184, 0.2)

### 7.6 动画效果
- **节点列表入场**：slideIn动画，依次延迟50ms
- **节点悬停**：translateX(4px) + 边框高亮
- **节点选中**：背景色变化 + 发光阴影
- **弹窗打开**：scale(0.95) → scale(1) + 淡入
- **播放进度条**：width过渡动画
- **通知提示**：从右侧滑入，2.5秒后滑出

## 八、设计原则

### 8.1 功能优先级
1. **节点时间轴**（核心功能载体）- 最高优先级
2. **播放控制区**（关键操作元素）- 次高优先级
3. **交互事件序列**（辅助信息展示）- 较低优先级

### 8.2 视觉层级
- 通过尺寸、颜色和位置关系明确各元素的重要性
- 引导用户注意力流向核心功能区域
- 减少用户执行核心任务的点击次数和视觉搜索成本

### 8.3 交互一致性
- 所有按钮使用统一的悬停和点击效果
- 所有卡片使用统一的圆角和阴影
- 所有弹窗使用统一的打开/关闭动画

### 8.4 反馈机制
- 操作成功：右上角显示通知提示
- 操作失败：显示错误提示，高亮错误字段
- 加载状态：显示加载动画
- 保存状态：工具栏显示保存状态指示器
