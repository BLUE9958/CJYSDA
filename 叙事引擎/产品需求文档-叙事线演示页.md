## 1. 文档概述

### 1.1 文档目的
本文档旨在定义叙事引擎演示页的产品需求，明确功能范围、用户交互流程及验收标准，为开发团队提供清晰的产品实现指导。

### 1.2 产品背景
叙事引擎演示页是叙事线的最终呈现形态，用于向终端用户展示完整的交互演示流程。与编辑页不同，演示页以场景内容为核心，叙事线控制为辅助，提供沉浸式的演示体验。

### 1.3 目标用户
- **主要用户**：演示观看者、产品体验用户
- **次要用户**：内容创作者（用于预览和演示）
- **用户特征**：无需任何专业背景，仅需基本的浏览器操作能力

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| **演示页** | 叙事线的播放展示页面，以场景内容为主，提供叙事线控制功能 |
| **当前节点** | 演示过程中正在执行或已执行完成的节点 |
| **节点进度** | 当前节点在整条叙事线中的位置，格式为"当前节点序号/总节点数" |
| **静默跳转** | 场景切换时无感知的自动跳转，由系统自动完成 |

## 2. 功能清单

### 2.1 核心功能

| 功能模块 | 功能项 |
|----------|--------|
| **场景展示** | 全屏展示场景内容、场景加载动画、场景切换（静默跳转） |
| **播放控制** | 上一步、下一步 |

| **全屏模式** | 点击全屏按钮进入全屏，ESC 退出全屏 |

| **键盘快捷键** | 方向键（上一步/下一步） |

### 2.2 异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| **加载失败** | 显示错误提示，提供重试按钮 |
| **场景资源加载失败** | 显示占位图，继续播放流程 |
| **节点数据异常** | 跳过异常节点，继续播放 |

## 3. 功能需求

### 3.1 详细功能说明

#### 3.2.1 场景内容展示

**功能描述：**
演示页以场景内容为核心，全屏或大面积展示场景画面。

**功能细节：**
- 场景内容占据100%视口区域
- 首次加载时显示加载动画
- 支持场景静默跳转（无感知切换）
- 控制元素悬浮于场景上层

> 
> 内容说明：展示全屏场景内容、悬浮控制层、模式提示

#### 3.2.2 播放控制

**功能描述：**
提供叙事线播放控制功能，支持手动控制播放进度。

**功能细节：**
- **上一步**：回退到上一个节点，执行该节点的交互事件序列（起始节点时禁用）
- **下一步**：执行下一个节点的交互事件序列（最后一个节点完成时禁用）
- **静默跳转**：相邻节点场景页不同时，系统自动完成场景切换，用户无感知

#### 3.2.3 进度展示

**功能描述：**
显示当前演示进度，让用户了解整体进度和当前位置。

**功能细节：**
- 格式："当前/总数"（如"0/4"）
- 悬停时可显示当前节点名称

#### 3.2.4 全屏模式

**功能描述：**
支持全屏播放，提供沉浸式演示体验。

**功能细节：**
- 点击全屏按钮进入全屏
- 按 ESC 键退出全屏

#### 3.2.5 远程控制

**功能描述：**
演示页内可直接启用/停用远程控制功能，手机扫码后可远程控制演示。

**功能细节：**
- 点击远程控制按钮打开弹窗，默认的功能状态以叙事线编辑页的设置为准
- 未启用状态：显示"启用"按钮，点击后开启远程控制
- 已启用-未连接状态：显示二维码、会话ID、"停用"按钮
- 已启用-已连接状态：显示会话ID
- 移动设备扫描二维码建立连接
- 远程控制支持上一步/下一步操作

#### 3.2.6 键盘快捷键

**功能描述：**
提供键盘快捷键，提升操作效率。

**功能细节：**
- **方向左键**：上一步
- **方向右键**：下一步

### 3.3 控制元素交互

**控制面板交互：**
- 点击展开按钮 → 展开控制面板，显示完整控制按钮
- 点击收起按钮 → 收起控制面板，仅显示进度和展开按钮

**按钮状态规则：**
- **上一步**：起始节点时禁用
- **下一步**：最后一个节点完成时禁用

## 4. 交互设计

### 4.1 整体交互流程

**核心交互模式：**
- 叙事线模式：用户通过控制按钮按序执行叙事线
- 自由演示模式：用户可直接与场景交互，不受叙事线限制

**模式切换逻辑：**
- 点击"上一步"或"下一步"按钮 → 进入叙事线模式
- 用户直接与场景交互（点击控点）→ 自动进入自由演示模式
- 再次点击"上一步"或"下一步" → 回到叙事线模式

### 4.2 详细交互流程

#### 4.2.1 页面加载流程
用户进入演示页，显示加载动画
加载叙事线配置数据
加载起始节点场景资源
场景渲染完成，显示场景，等待用户操作

#### 4.2.2 播放控制流程
用户点击"下一步"
检测场景是否需要切换（静默跳转），若需要则先切换场景
执行下一个节点的交互事件序列
更新进度指示器

#### 4.2.3 远程控制流程
用户点击远程控制按钮
打开远程控制弹窗
点击"启用"按钮
生成二维码和会话ID
用户使用手机扫描二维码
建立远程控制连接
手机端可控制上一步/下一步操作
点击"停用"按钮断开连接
