## 1. 文档概述

### 1.1 文档目的
本文档旨在定义免登录远程控制（移动端）的优化需求，明确功能范围、用户交互流程及验收标准，为开发团队提供清晰的产品实现指导。

### 1.2 产品背景
免登录远程控制功能是场景演示大师产品的重要组成部分，用于帮助演示者通过移动设备远程控制场景演示和叙事线播放。本次优化旨在提升用户体验，支持更多场景，并适配不同尺寸的移动设备。

### 1.3 目标用户
- **主要用户**：演示观看者、产品体验用户
- **次要用户**：内容创作者（用于预览和演示）
- **用户特征**：无需任何专业背景，仅需基本的浏览器操作能力

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| **远程控制** | 通过移动设备对电脑端演示进行实时操作的功能 |
| **会话ID** | 用于建立远程连接的唯一标识符 |
| **静默跳转** | 场景切换时无感知的自动跳转，由系统自动完成 |
| **普通预览页** | 场景的直接预览页面，支持自由交互 |
| **叙事线预览页** | 按照预设节点顺序播放的叙事线预览页面 |

### 3.2 核心功能模块

#### 3.2.1 连接管理

**功能描述：**
提供多种方式建立与电脑端的连接，确保远程控制的可靠性。

**功能细节：**
- **二维码扫描**：
  - 内置二维码扫描器
  - 自动识别控制二维码
  - 扫描后自动建立连接
- **会话ID输入**：
  - 支持手动输入会话ID
  - 会话ID格式验证
  - 连接状态反馈
- **连接状态**：
  - 显示当前连接状态（未连接/连接中/已连接/连接失败）
  - 连接失败时显示错误信息
  - 网络断开时自动重连
- **历史记录**：
  - 保存最近的连接记录
  - 快速重连历史设备
  - 记录连接时间和设备信息

#### 3.2.2 播放控制

**功能描述：**
提供完整的演示播放控制功能，支持各种播放操作。

**功能细节：**
- **普通预览模式**：
  - 场景切换控制
  - 弹窗控制
  - 媒体播放控制
- **叙事线模式**：
  - 上一步按钮：回退到上一个节点
  - 下一步按钮：前进到下一个节点
  - 播放/暂停按钮：控制演示的播放和暂停
  - 停止按钮：停止当前演示
- **进度控制**：
  - 可视化进度条
  - 点击进度条任意位置跳转
  - 显示当前节点和总节点数
- **快捷操作**：
  - 双击屏幕快速切换到下一步
  - 下拉刷新重新连接
  - 手势控制（如左右滑动切换节点）

#### 3.2.3 状态同步

**功能描述：**
实时同步电脑端的演示状态，确保移动端控制的准确性。

**功能细节：**
- **状态同步**：
  - 实时同步当前节点信息
  - 同步场景切换状态
  - 同步播放/暂停状态
- **网络状态**：
  - 显示网络连接质量
  - 网络不稳定时提示
  - 断网重连提示
- **错误处理**：
  - 连接超时提示
  - 权限不足提示
  - 设备离线提示

#### 3.2.4 响应式设计

**功能描述：**
适配不同尺寸的移动设备，提供良好的用户体验。

**功能细节：**
- **手机适配**：
  - 单列布局
  - 大尺寸触控按钮
  - 垂直排列控制元素
  - 优化手势操作
- **Pad适配**：
  - 双列布局
  - 右侧快捷操作面板
  - 更大的控制区域
  - 支持更多快捷键操作

  - 当前播放状态指示

  - 下一步按钮（大尺寸，右侧）

### 7.2 风险与注意事项

| 风险点 | 应对方案 |
|--------|----------|
| 网络延迟 | 优化WebSocket连接，添加缓冲机制 |
| 连接稳定性 | 实现自动重连和心跳检测 |
| 设备兼容性 | 测试主流移动设备，适配不同屏幕 |
| 电池消耗 | 优化网络请求，减少后台运行 |

### 7.3 操作流程

**连接流程：**
1. 打开移动端应用
2. 扫描电脑端生成的二维码或输入会话ID
3. 系统自动建立WebSocket连接
4. 连接成功后进入控制界面
5. 自动识别当前预览模式（普通/叙事线）

**控制流程：**
1. 在控制界面查看当前演示状态
2. 根据模式选择控制按钮
3. 系统发送控制指令到电脑端
4. 电脑端执行相应操作并返回状态
5. 移动端同步更新状态

**断开流程：**
1. 演示结束或手动断开连接
2. 系统清理连接资源
3. 返回连接界面，等待下一次连接
